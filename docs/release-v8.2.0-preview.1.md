## OMP Live Map v8.2.0-preview.1

- Live Map 상단의 **새 실행**에서 프로젝트, 템플릿, 작업 목표와 완료 조건을 입력합니다. 실행을 시작하면 같은 캔버스에서 Workflow와 현재 단계를 엽니다.
- **개입 필요**에서 승인 대기, 실패, 확인 필요 실행을 찾고 해당 노드를 바로 엽니다. 최근 실행도 다시 열 수 있습니다.
- 실행 상세에서 로그와 산출물을 확인하고 검증 재실행, 수정 요청, 승인 또는 반려를 처리합니다.
- 실행을 닫으면 이전 캔버스 위치로 돌아갑니다. 자유 배치한 세션 카드와 Workflow 노드 좌표는 보존됩니다.

Windows x64 설치 파일과 SHA-256 체크섬을 제공합니다. Windows 프리릴리스 설치 파일에는 코드 서명이 적용되지 않았습니다.
