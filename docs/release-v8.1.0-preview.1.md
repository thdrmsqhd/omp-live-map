## OMP Live Map v8.1.0-preview.1

- Engineering에서 역할·모델·읽을 자료·결과 형식을 GUI로 편집하고, 동일 입력으로 하네스 버전을 비교할 수 있습니다.
- 관제에서 새 Workflow를 실행하고, 기존 Live Map에서 노드를 자유롭게 배치하며 진행과 증거를 확인할 수 있습니다.
- 실패 노드 재실행·수정 요청, 승인·반려, 그래프 변경의 새 버전 저장을 지원합니다.

Windows x64 설치 파일과 SHA-256 체크섬을 제공합니다. 이 설치 파일은 코드 서명이 적용되지 않은 프리릴리스입니다. 실제 인증된 OMP·Claude Code 환경에서의 업무 실행은 별도 검증이 남아 있습니다.
