# OMP Live Map V3 진행 현황

V3는 기존 합의에 따라 Phase 4~6을 대상으로 합니다. V2의 Windows 설치 및 단일 Loop는 V2 브랜치에서 유지합니다. V3의 워크플로우 정의는 기존 프로젝트와 Loop 정의를 재사용하고, V2 관측 API의 세션 그래프와 별도 경로에서 편집합니다.

| Task | 구현 | 검증 |
| --- | --- | --- |
| T031 (REQ-018, REQ-021) | Start, End, Agent, Command, Loop, Condition, Parallel, Join, Approval, 입출력 포트와 산출물 참조, Agent/Loop 버전 고정, SQLite v1 → v2 마이그레이션 | 정의 재조회, 프로젝트 경계, 참조된 정의 보호, 이전 버전 보존 |
| T032 (REQ-019) | 도달성, 선행관계, 중복·누락 포트, 순환, 구조화 조건, 산출물 경로 검증 및 결정적 실행 순서 생성 | 정상·누락·순환·경로·조건 입력 테스트 |
| T033 (REQ-020) | 저장된 Workflow 버전의 순차·조건 실행 및 실행 상태 조회, 기존 격리 백엔드 경유 | 모의 명령으로 실패 분기 → 승인 대기 → 성공 및 멱등 재요청 검증 |
| T034, T036, T037, T039 일부 | Join의 활성 선행관계 계산, 기본 승인·거절, 상태·실행 목록, 일시정지·취소·재개, 불확실 노드 재실행 차단 | 계획과 저장소 테스트에서 Join, 승인 대기, 중단 기록 검증 |
| T038 (REQ-018, REQ-019) | 별도 Workflow 화면에서 노드와 연결 추가·삭제, 드래그, 속성, 계획 미리보기, 저장 및 다시 열기 | Windows 데스크톱 테스트에 편집·이동·저장·재조회 시나리오 추가 |

분기 내 외부 노드의 동시 실행, 산출물 계약 실행 및 해시 기반 승인, 선택 노드 재시도, 실행 그래프 오버레이와 Subgraph는 후속 구현입니다. Phase 5의 SDLC 및 Phase 6의 설치·최종 인수는 해당 Graph 실행 기반을 사용합니다. 데이터 이관 시험은 이전 V2 DB 사본으로 실행합니다.
