## HED-01 · 기존 정의와 실행 범위 확인

| 설정 | OMP | Claude Code |
|---|---|---|
| 모델 | 저장된 모델 정의 버전 사용. 실행 어댑터에서 지원 조합 확인 | 저장된 모델 정의 버전 사용. 추론 수준 설정은 현재 격리 어댑터에서 미지원 |
| 역할, 지시, AGENTS.md, Skills | 작업 프롬프트에 합성 | 작업 프롬프트에 합성 |
| 실행 위치와 권한 | 관리되는 Git worktree, 런타임에서 격리 강제 | 관리되는 Git worktree, 런타임에서 격리 및 도구 목록 강제 |
| MCP, Hooks | 초안 저장, 실행 시 적용되지 않음 | 초안 저장, 실행 시 적용되지 않음 |

Workflow는 저장 시 하네스 버전을 고정합니다. 하네스와 Loop 정의의 참조도 버전별로 저장됩니다.

검증: Engineering API·어댑터·정의·Workflow 테스트 16건 통과. OMP와 Claude Code 실행은 테스트 프로토콜로 검증했습니다.

## HED-02 · 폼 기반 프로필 편집

역할 템플릿, 모델 이름 선택, 프로필 복제, 지시와 프로젝트 규칙 편집, 스킬 추가·삭제, MCP·Hooks 초안 편집을 추가했습니다. 기존 모델·Loop JSON 정의 편집 경로와 하네스 버전 저장 API를 사용합니다.

검증: JavaScript 모듈 구문 검사, `git diff --check`, Node 테스트 52건 통과. 이 환경의 Chromium 프로세스가 시작되지 않아 폼의 브라우저 통합 검증은 남아 있습니다.

## HED-03 · 적용값 미리보기 API

저장본의 고정 모델 버전과 초안을 구분하고, 실제 어댑터와 같은 지시 합성 및 실행 가능 여부 검사 경로를 사용합니다. 실행 가능한 격리 어댑터의 도구와 작업 범위를 표시합니다.

검증: 저장된 하네스는 기존 모델 버전을 유지하고 초안은 현재 모델을 사용합니다. 미준비 런타임과 MCP·Hooks 초안 상태도 확인했습니다. Node 테스트 52건 통과.

## HED-04 · 편집기와 적용값 미리보기 연결

편집 초안과 선택한 저장 버전의 미리보기를 각각 열 수 있습니다. 변경된 입력이나 프로필로 전환하면 이전 결과를 지우고 늦게 도착한 응답을 표시하지 않습니다. 쓰기 제한은 런타임에서 강제되는 현재 범위로 표시하며 읽기 전용을 선택하는 조작은 제공하지 않습니다.

검증: 모듈 구문 및 diff 검사, Node 테스트 52건 통과. GUI 실제 동작 확인은 남아 있습니다.
