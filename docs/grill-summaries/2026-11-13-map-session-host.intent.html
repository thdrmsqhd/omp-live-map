카드 하나는 일하는 주체 하나입니다. 메인 에이전트, 서브에이전트, 잡이 모두 "지금 하는 일이 실시간으로 흐르는 칸 + 멈춤 + 지시"를 갖습니다. 서브에이전트 카드는 지금도 메인과 같은 블록으로 열리지만 실시간 흐름과 멈춤·지시가 없습니다.

지금 얼마나 늦게, 얼마나 얕게 보이나: 8개 항목 (server/ingest.js, turns.js, server.js, ui/js/app.js 대조)

무엇을지금 보이는 것과 늦는 정도목표정보가 오는 곳
에이전트·서브에이전트가 쓰는 글메시지가 끝난 뒤, 앞 700자만. 맵에서 보낸 지시의 메인 답변만 글자 단위쓰는 즉시, 전체실시간 이벤트 맵이 직접 띄운 세션에서 받는다
생각안 보임쓰는 즉시기록에 있음 이 세션 기록에 47개. 맵이 읽지 않는다
툴 호출시작하고 0.3~2초 뒤. 툴 이름과 횟수만시작 즉시, 인자까지 시간순으로기록에 있음 시작 시각과 인자가 써진다. 맵이 버린다
툴 결과안 보임. 실패 횟수만 센다끝나는 즉시, 내용까지기록에 있음 맵이 버린다
실행한 명령최근 8개, 앞 140자. 출력 없음전체 명령과 출력기록에 있음 맵이 버린다
에이전트가 띄운 잡잡 번호, 명령, 실행 중·종료, 시각. 출력 없음출력이 줄 단위로 흐른다. 중지실시간 이벤트 맵이 직접 띄운 세션에서만 받는다. 디스크에는 남지 않는다
맵에서 띄운 잡1.2초마다 최근 80줄줄이 나오는 즉시맵 서버 프로세스를 맵이 갖고 있어 바로 보낼 수 있다
자원·금액자원은 4초 주기. 금액은 메시지가 끝날 때그대로 둔다금액은 omp가 메시지 끝에 계산한다

조건: 글자 단위 실시간과 조종은 맵이 직접 띄운 세션에서만 완전하게 됩니다. 터미널에서 따로 띄운 세션은 기록 파일로만 보이므로 툴 호출은 0.3~2초 뒤, 글은 메시지가 끝난 뒤에 나옵니다.

만드는 순서 제안 (확정 전)

  1. 맵이 세션을 직접 띄운다. 새 세션, 종료, 지시, 멈춤. 실시간의 전제다
  2. 실시간 흐름. 메인과 서브에이전트의 글·생각·툴 호출·결과가 시간순으로 흐른다
  3. 모델과 단가 표시. 비싼 모델이 직접 일하는 카드가 눈에 띄게 한다
  4. 서브에이전트 카드. 하나만 멈추기, 직접 지시
  5. 잡 카드. 출력 스트리밍, 중지. 에이전트가 띄운 잡의 출력 위치 실험이 먼저다
  6. 질문에 답하기, 파일 첨부
  7. 전체 합계 줄, 금액 기준
아직 정하지 않은 4개
