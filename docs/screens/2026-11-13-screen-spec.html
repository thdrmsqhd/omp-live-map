화면정의서: 맵 업무 OS

맵 하나에서 세션·서브에이전트·잡을 같은 급의 카드로 두고, 각 카드가 지금 하는 일을 실시간으로 보면서 그 자리에서 조종하는 화면을 정의한다.

범례: 주황 테두리: 신규 요소 (두께 2.5) 회색 테두리: 기존 요소 (두께 1.2) 1 동그라미 번호: 오른쪽 표의 번호와 1:1 대응

화면 목록

번호 이름 여는 방법 단계
S1 맵 전체 http://127.0.0.1:7800 을 연다 기존(합계 줄만 6단계)
S2 새 세션 창 S1 상단의 + 새 세션 을 누른다 1단계(첨부는 5단계)
S3 에이전트 카드(메인·서브에이전트 공통, 열린 상태) 작은 카드를 더블클릭한다 1~3단계(질문·첨부는 5단계)
S4 잡 카드(열린 상태) 잡 작은 카드를 더블클릭한다 4단계
S5 작은 카드와 상태 표시 S1 의 카드가 접힌 모습 1~5단계

S1 맵 전체

요소 설명

번호 요소 보여 주는 것 누르면 일어나는 일 기존/신규 단계
1-1 상단 합계 줄 지금 맵에 있는 세션 수, 에이전트 수, 오늘 쓴 비용, 이 PC 의 RAM·CPU 없음(보기만) 신규 6
1-2 + 새 세션 버튼 새 세션을 여는 입구 S2 를 연다 신규 1
1-3 세션 묶음 세션 하나에 속한 메인 카드·서브에이전트 카드·잡 카드를 묶는 테두리와 제목 클릭하면 그 묶음을 고른다(Shift+클릭 다중 선택) 기존 -
1-4 메인 에이전트 카드 상태 점, 이름, 컨텍스트 사용률, 토큰 구성, 비용 요약 더블클릭하면 S3 를 연다 기존 -
1-5 서브에이전트 카드 상태 점, 이름, 컨텍스트, 토큰, 세션 합계 자원 더블클릭하면 S3 를 연다 기존 -
1-6 잡 카드 잡 번호, 명령 앞부분, 실행 중인지 끝났는지, 시작 시각 더블클릭하면 S4 를 연다 기존 -
1-7 이 PC 카드 RAM, CPU, 디스크, 가동 시간 카드 메뉴를 연다 기존 -
1-8 WSL·Docker 카드 배포판·컨테이너 목록과 상태 start·stop·restart 를 보낸다 기존 -
1-9 거르기·검색·확대 상단 바의 거르기, 검색, 확대 버튼 기존 조작은 README 참고 기존 -

상태별 화면 모습

상태 화면에 나타나는 모습
세션이 없음 합계 줄이 모두 0 이고 카드가 하나도 없다. + 새 세션 만 남는다.
세션 3개 이상이 동시에 돎 세션 묶음이 3개 이상 늘어서고, 도는 중인 카드의 상태 점이 깜박인다.
큰 카드가 열림 그 자리에 미러 카드가 남고, 큰 카드는 그 위에 겹쳐 뜬다.
TUI 세션만 있음 카드는 보이지만 읽기 전용이고 TUI 사용 중 이 붙는다.
거르기가 걸림 거른 조건에 맞지 않는 카드가 흐려지거나 빠진다.
합계 값을 낼 수 없음 그 칸에 값을 채우지 못하는 경우의 표시는 미정이다.

S2 새 세션 창

요소 설명

번호 요소 보여 주는 것 누르면 일어나는 일 기존/신규 단계
2-1 작업 폴더 선택 새 세션이 일할 폴더. 기본값은 OMP_MAP_CWD 폴더를 고르거나 경로를 친다 신규 1
2-2 첫 지시 입력 처음 보낼 지시 글 친 내용이 첫 지시가 된다 신규 1
2-3 파일·이미지 첨부 붙인 파일 이름 목록과 빼기 표시 파일을 고르면 목록에 더한다. x 를 누르면 뺀다 신규 5
2-4 열기 이 폴더로 세션을 시작하는 버튼 그 폴더에 omp --mode rpc-ui 를 띄우고 첫 지시를 보낸다. S1 에 그 세션 묶음이 생긴다 신규 1
2-5 취소 창을 닫는 버튼 아무것도 띄우지 않고 창을 닫는다 신규 1

상태별 화면 모습

상태 화면에 나타나는 모습
작업 폴더를 아직 고르지 않음 기본 폴더가 채워져 있고 열기 를 누를 수 있다.
첫 지시가 비어 있음 열기 를 누르면 빈 지시로 세션만 열린다(빈 세션과 같은 상태).
첨부가 있음 파일 이름이 줄로 붙고 각 줄에 x 가 있다.
열기를 누른 뒤 기다리는 동안 버튼이 잠기고 세션이 뜨는 동안의 표시가 나온다. 걸리는 시간은 약 1.6초다.
열기가 실패함 폴더가 없거나 omp 가 뜨지 않은 경우의 문구는 미정이다.
취소를 누름 창이 닫히고 맵으로 돌아간다.

S3 에이전트 카드(메인·서브에이전트 공통, 열린 상태)

요소 설명

번호 요소 보여 주는 것 누르면 일어나는 일 기존/신규 단계
3-1 상태 점과 이름 이 카드가 도는 중인지, 답을 기다리는지, 중단됐는지 없음(보기만) 기존 -
3-2 모델 이름과 단가 이 카드에 붙은 모델 이름, 100만 토큰당 단가. 비싼 모델이 직접 일하면 눈에 띄게 강조한다 없음(보기만) 신규 2
3-3 금액·토큰·컨텍스트 누적 금액, 출력·입력 토큰, 컨텍스트 사용률 토큰 막대를 누르면 누적과 최근 1시간이 바뀐다 기존 -
3-4 멈춤 지금 도는 턴을 멈추는 버튼 그 턴의 프로세스 트리를 끝낸다 기존(취소) 1
3-5 세션 종료 rpc 프로세스를 끝내 세션을 놓는 버튼. 메인 카드에만 있다 세션이 빈 세션이 되고 카드가 끝남 으로 바뀐다 신규 1
3-6 실시간 흐름 칸 주체가 내는 일을 생기는 즉시 시간순으로 쌓는다. 항목 종류는 생각, 툴 호출과 인자, 툴 결과, 명령과 출력, 고친 파일, 잡 띄움, 쓰는 중인 글 일곱 가지다 줄을 누르면 그 툴을 쓴 턴으로 대화를 거른다 신규 2
3-7 질문 상자 에이전트가 ask 로 되물은 내용과 고를 수 있는 답 답을 누르면 그 답을 rpc 로 돌려주고 턴이 이어진다 신규 5
3-8 입력창 지시를 치는 칸과 보내기 보내기 를 누르면 지시를 보낸다. 도는 중에 보내면 추가 지시(steer)가 된다 신규 메인 1, 서브 3
3-9 파일 첨부 붙인 파일·이미지 목록 파일을 고르면 다음 지시에 붙는다 신규 5
3-10 기존 블록 파일 트리, 터미널, 브라우저 미리보기 블록마다 접기·순서 변경·높이 조절 기존 -

서브에이전트 카드도 메인과 같은 틀을 씁니다. 다른 점은 세션 종료 가 없고, 자원(CPU·메모리)은 카드별이 아니라 세션 합계로 보여 주는 두 가지입니다.

상태별 화면 모습

상태 화면에 나타나는 모습
도는 중 상태 점이 깜박이고, 실시간 흐름에 새 줄이 계속 붙는다. 멈춤 이 눌린다.
멈춤을 누른 직후 마지막 줄에 취소 표시가 남고 점이 조용해진다.
답을 기다리는 중 질문 상자가 펼쳐지고 점이 다른 색이 된다.
중단됨 점이 회색이고 이어 가기 가 뜬다.
끝남(세션 종료 뒤) 점이 비어 있고 입력창이 잠긴다. 지시를 보내면 다시 맵 세션이 된다.
TUI 사용 중 실시간 흐름과 입력창이 읽기 전용이고, 기록 tail 로만 갱신된다.
실시간 흐름이 비어 있음 맵이 띄우지 않은 세션이면 이벤트가 없어 칸이 빈다.

S4 잡 카드(열린 상태)

요소 설명

번호 요소 보여 주는 것 누르면 일어나는 일 기존/신규 단계
4-1 상태 점과 명령 잡이 실행 중인지 끝났는지, 돌린 명령 없음(보기만) 기존 -
4-2 걸린 시간 시작한 뒤 지난 시간 없음(보기만) 신규 4
4-3 종료 코드 끝난 잡의 종료 코드. 도는 중에는 빈칸 없음(보기만) 신규 4
4-4 띄운 주체 이 잡을 띄운 에이전트 그 에이전트 카드로 이동한다 신규 4
4-5 중지 도는 잡을 끝내는 버튼 잡 프로세스를 끝낸다 기존(중지) 4
4-6 출력 칸 잡의 표준 출력과 표준 오류. 줄이 나오는 즉시 흐른다 끝까지 올라간 뒤에는 스크롤해 볼 수 있다 신규 4

상태별 화면 모습

상태 화면에 나타나는 모습
실행 중 점이 깜박이고 출력 칸에 줄이 계속 붙는다. 종료 코드는 빈칸이다.
끝남(코드 0) 점이 조용해지고 종료 코드에 0 이 뜬다. 마지막 줄까지 남아 있다.
끝남(코드 0 아님) 종료 코드에 그 값이 뜨고 카드가 눈에 띄게 표시된다.
중지를 누름 출력이 멈추고 종료 코드가 중지 값으로 채워진다.
출력이 없음 칸이 비어 있고 도는 중이면 계속 출력 중 만 보인다.
TUI 세션의 잡 출력 칸이 비어 있고, 명령과 상태만 보인다.

S5 작은 카드와 상태 표시

요소 설명

번호 요소 보여 주는 것 누르면 일어나는 일 기존/신규 단계
5-1 상태 점 카드가 어느 상태인지 점 모양과 색으로 보여 준다 없음(보기만) 기존(일부 신규) 1~5
5-2 이름과 소속 카드 이름, 어느 세션의 메인인지 서브인지 이름을 더블클릭하면 이름을 바꾼다 기존 -
5-3 요약 지표 컨텍스트 사용률, 토큰 구성, 턴당 출력 추세, 세션 프로세스 CPU·메모리 없음(보기만) 기존 -
5-4 짧은 조종 그 상태에서 바로 쓸 수 있는 버튼 아래 표의 조종을 실행한다 신규 1~5

상태별 화면 모습 및 조종

상태 화면에 나타나는 모습 이 상태에서 되는 조종
도는 중 점이 깜박이고 이름 옆에 지금 도는 중 표시 멈춤, 도는 중 추가 지시, 더블클릭해 열기
답을 기다리는 중 점이 다른 색으로 깜박이고 ? 표시 질문에 답하기, 멈춤
중단됨 회색 점과 중단됨 글자 이어 가기(omp --restore), 세션 종료
끝남 빈 점, 조용한 카드 지시 보내기(보내면 맵 세션이 된다), 더블클릭해 열기
TUI 사용 중 ▣ 표시와 TUI 사용 중 글자, 카드가 읽기 전용 없음. 보기만 하고 지시를 보내지 않는다
빈 세션 · 표시, 조용한 카드 지시 보내기, 세션 종료

정해지지 않은 것

4차 정리의 Open threads 및 모델·단가 표시에서 정할 항목 목록입니다.

에이전트가 띄운 잡의 실시간 출력을 읽을 수 있는가 (계획 첫 실험으로 둠)
금액 기준: "제한 없음"과 "초과 시 알림 또는 멈춤"이 갈려 있음 (알림/멈춤 및 기준 금액 확정 필요)
글자 단위 실시간과 조종은 맵이 띄운 세션에서만 완전함 (TUI 세션의 0.3~2초 tail 지연 수용 여부)
서브에이전트별로 자원을 나눠 잴 수 있는가
툴 결과 전체를 서버 메모리에 둘지, 카드를 열 때 기록에서 읽을지 (README의 메모리만 유지 정책)
첨부 파일을 omp 에 넘기는 방법 (임시 폴더 저장 시 디스크 무기록 원칙 예외 발생)
단가를 어디서 가져올지 (omp 모델 설정 또는 기록의 메시지별 비용)
"비싼 모델"의 기준
"직접 일한다"의 판정 (툴 호출을 직접 하는지)
