M4 맵에서 조종하기

맵을 떠나지 않고 세션을 열고, 멈추고, 지시한다.

번호 요소 보여 주는 것 누르면 일어나는 일 기존/신규
1 새 세션 (빈 바탕 메뉴) 빈 캔버스 바탕 우클릭 시 나타나는 새 세션 생성 메뉴 항목 중앙에 '새 세션 창' 대화상자를 띄워 작업 폴더와 지시를 입력받습니다. 신규
2 새 세션 창 작업 폴더 경로, 첫 지시 입력란, 파일 첨부 영역, 열기·취소 버튼 '열기' 클릭 시 지정 폴더에서 새 백그라운드 세션을 기동하고 맵에 새 세션 묶음 카드를 추가합니다. '취소' 클릭 시 창을 닫습니다. 신규
3 새 로컬 카드 (빈 바탕 메뉴) 빈 캔버스 바탕 우클릭 시 나타나는 로컬 카드 추가 항목 클릭한 캔버스 좌표에 메모나 체크리스트를 적을 수 있는 빈 로컬 카드를 만듭니다. 기존
4 전체 보기 (빈 바탕 메뉴) 캔버스에 배치된 모든 카드를 한 화면에 맞추는 뷰포트 정렬 메뉴 항목 현재 맵의 모든 카드가 중앙에 들어오도록 줌 배율과 스크롤 위치를 자동 조정합니다. 기존
5 카드 우클릭 조종 메뉴 멈춤, 지시 보내기, 세션 종료(메인 전용), 잡 중지(잡 카드 전용) 항목 - 멈춤: 실행 중인 에이전트에 일시정지 신호를 보냅니다.
- 지시 보내기: 인라인 입력칸을 띄워 진행 중인 에이전트에 즉시 추가 프롬프트를 전송합니다.
- 세션 종료: 메인 에이전트 및 연관 서브프로세스를 모두 안전하게 종료합니다.
- 잡 중지: 실행 중인 백그라운드 잡(npm/테스트/빌드 등) 프로세스를 kill합니다. 		신규
6 카드 우클릭 관리 메뉴 프로세스 정리, 숨기기, 고정 메뉴 항목 비정상 종료된 고아 프로세스를 정리하거나, 맵 화면에서 카드를 숨기거나, 드래그 이동을 잠급니다. 기존
7 질문 말풍선 (답 대기 카드) '에이전트가 묻습니다' 제목, 에이전트의 구체적 질문 문구, 2가지 선택 버튼 원하는 선택 버튼을 누르면 해당 답변 텍스트가 에이전트에 즉시 입력되어 대기 상태가 해제되고 작업이 재개됩니다. 신규
8 TUI 세션 카드 터미널에서 직접 실행된 외부 세션을 반투명하게 표시하고 '보기만' 배지 노출 클릭해도 상태 흐름만 열람할 수 있으며, 멈춤·지시·종료 등 조종 메뉴는 비활성화됨을 안내합니다. 신규
9 세션 묶음 (카드 및 연결선) 메인 에이전트 카드, 서브에이전트 카드, 잡 카드가 계층 관계선으로 묶인 단위 카드 더블클릭 시 큰 카드(상세 패널)를 열고, 묶음 제목이나 메인 카드를 끌면 묶음 전체가 함께 이동합니다. 기존
