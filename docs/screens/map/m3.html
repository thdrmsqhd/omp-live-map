M3 맵 위에서 카드 여러 장 열기

작은 카드를 열면 맵 위에 큰 카드가 펼쳐진다. 여러 장을 동시에 열어 나란히 본다.

번호 요소 보여 주는 것 누르면 일어나는 일 구분
1 세션 묶음 한 세션에 속한 메인/서브에이전트, 잡 카드들의 클러스터 그룹 영역 묶음 타이틀 클릭 및 드래그 시 세션 소속 카드 전체를 맵 위에서 일괄 이동 기존
2 작은 카드 (기본) 에이전트 이름, 모델명, 토큰 사용량, 현재 상태 요약 표시 더블클릭 시 맵 우측 캔버스 영역에 해당 카드의 큰 카드가 열림 기존
3 열린 자리 표시 카드 이미 큰 카드로 펼쳐진 작은 카드 자리에 흐린 점선 테두리로 열림 상태 표시 클릭 시 이미 열려 있는 해당 큰 카드로 시선 포커스 및 강조 이동 신규
4 카드 연결선 세션 묶음 내 작은 카드와 맵 위에 펼쳐진 큰 카드 사이를 잇는 곡선 가이드 마우스 오버 시 연결선이 강조되어 어떤 작은 카드가 열린 상태인지 즉시 식별 신규
5 카드 동시 열기 단일 모달이 아닌 맵 캔버스 위에 여러 장의 큰 카드를 나란히 동시 배치 원하는 카드를 계속 더블클릭하여 나란히 띄우고 비교 관제 가능 신규
6 메인 에이전트 큰 카드 메인의 상태, 누적 토큰 비용, 실시간 흐름, 하단 전송 입력창을 한눈에 표시 상단 드래그로 맵 상 위치 이동, X 버튼 클릭 시 큰 카드 닫기 기존
7 서브에이전트 큰 카드 서브에이전트의 구체적 작업 맥락, 모델명, 실시간 진행 로그 및 전용 제어부 개별 서브의 작업 상황을 독립적으로 확인 및 제어 신규
8 잡 큰 카드 백그라운드 실행 중인 프로세스(Vite, 테스트 등)의 PID, 포트, 터미널 스트림 상단 헤더 드래그로 위치 이동 및 백그라운드 잡 상세 관제 신규
9 멈춤 / 중지 버튼 메인/잡의 중지(Kill) 및 서브에이전트 일시멈춤 제어 버튼 클릭 시 즉시 해당 에이전트 또는 잡 프로세스에 중지/정지 시그널 전송 신규
10 에이전트 실시간 흐름 칸 생각(파랑) · 도구 호출(보라) · 실행 결과(초록/빨강) · 출력 텍스트 4줄 스트림 각 로그 항목 클릭 시 세부 페이로드 및 전체 입출력 JSON 팝업 확인 신규
11 잡 콘솔 흐름 칸 어두운 콘솔 배경(#1e293b)에 표준 출력(stdout) 및 에러(stderr) 스트림 4줄 이상 마우스 휠 스크롤로 이전 로그 버퍼 탐색, 텍스트 선택 및 복사 가능 신규
12 프롬프트 입력창 선택한 에이전트(메인 또는 개별 서브)에게 직접 추가 프롬프트 지시 입력창 텍스트 입력 후 '전송' 또는 Enter 시 해당 에이전트에게 지시문 즉시 주입 (잡 카드는 미제공) 신규
