M2 맵 위에서 보이는 실시간

카드를 열지 않아도 각 카드가 지금 하는 일이 맵 위에서 흐른다.
* 본 화면의 카드 내 작업 내용, 도구 호출명, 콘솔 로그, 모델명 및 수치는 실시간 관제 이해를 돕기 위한 예시 데이터입니다.
번호 요소 보여 주는 것 누르면 일어나는 일 구분
1 세션 묶음 (클러스터) 세션 ID, 세션 주 목적, 소속 에이전트 및 잡 카드의 시각적 묶음 점선 영역 빈 영역 클릭 시 세션 전체 포커스, 더블클릭 시 세션 전체 펼치기/접기 기존
2 메인 에이전트 카드 전체 세션을 총괄하는 메인 모델 카드, 상태, 토큰량, 실시간 오케스트레이션 현황 더블클릭 시 큰 메인 카드(전체 턴 대화 및 도구 이력) 열기, 우클릭 시 메뉴 기존
3 서브에이전트 A 카드 분할된 하위 작업(수집/조사) 전담 모델 카드, 현재 사용자 응답 대기 상태 더블클릭 시 서브 대화 세부 보기, 클릭 시 대기 중인 사용자 입력창 바로 열기 기존
4 서브에이전트 B 카드 실행 중인 하위 작업(코드 파싱) 카드 및 현재 백그라운드 잡과의 연계 상태 더블클릭 시 상세 로그 및 실행 트레이스 열기 기존
5 상태 점 (Status Dot) 에이전트의 현재 활동 상태 (초록 #0f766e: 실행 중, 주황 #e8590c: 대기/답변 대기, 회색: 완료) 상태 툴팁 표시 및 일시정지/재개 단축 액션 기존
6 고비용 모델 경고 띠 및 단가 배지 비싼 모델(Opus 등)이 직접 실무 코딩이나 읽기를 수행할 때 주의를 환기하는 주황 띠와 모델 단가 레벨 클릭 시 저비용 서브에이전트 위임 권고 팝업 또는 모델 변경 옵션 표시 신규
7 컨텍스트 및 비용 수치 누적 사용 토큰 비율(%), 턴 수, 현재까지 발생한 누적 달러($) 비용 클릭 시 토큰 사용량 차트 미니 팝업 표시 기존
8 실시간 한 줄 활동 흐름 카드를 열지 않고도 맵 위에서 바로 보이는 현재 행동 (`지금: 파일 읽는 중 · ingest.js` 등) 클릭 시 해당 도구 호출 상세 로그 위치로 즉시 스크롤 및 큰 카드 열기 신규
9 잡 콘솔 2줄 스트리밍 백그라운드에서 실행 중인 프로세스의 최신 stdout/stderr 마지막 2줄을 터미널 스타일로 실시간 출력 클릭 시 전체 터미널 실시간 스트리밍 모달 팝업 열기 신규
10 답 대기 주황 테두리 강조 사용자 입력이나 확인 승인이 필요해 멈춰 있는 카드를 맵 전체에서 한눈에 찾도록 주황 테두리로 강조 클릭 시 즉시 해당 에이전트의 프롬프트 응답 입력 포커스로 이동 신규
11 일 나눔 연결선 및 라벨 메인이 서브에이전트에게 할당한 작업 관계선 위에 '일 나눔' 배지를 띄워 위임 관계 명시 연결선 클릭 시 전달된 서브태스크 목표와 계약(Contract) 요약 툴팁 표시 신규
