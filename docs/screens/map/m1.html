M1 맵 전체 배치

세션 여러 개와 에이전트 여러 개가 맵 한 장에 놓인 모습.

번호 요소 보여 주는 것 누르면 일어나는 일 기존/신규
1 합계 줄 전체 세션 수, 전체 에이전트 수, 당일 누적 LLM 비용($), 시스템 전체 RAM/CPU 사용량 실시간 요약 누르면 세부 비용 및 리소스 사용량 차트 팝업 또는 상세 모달 표시 신규
2 + 새 세션 버튼 맵 상에서 즉시 새 OMP 세션을 시작할 수 있는 액션 버튼 누르면 새 세션 생성 다이얼로그(모델 선택, 작업 디렉터리, 초기 프롬프트) 표시 신규
3 거르기·검색·확대 도구 세션 검색창, 상태별 필터(전체, 도는 중, 대기, 끝남), 줌 배율 제어(+/-) 버튼 입력 시 일치하는 세션/에이전트 카드로 맵 포커스 이동 및 필터링 적용 기존
4 세션 묶음 (도는 중) 진행 중인 세션명, 실시간 진행 상태 점(#0f766e 녹색), 메인/서브에이전트/잡 포함 컨테이너 제목 영역 드래그 시 묶음 전체 이동, 더블클릭 시 세션 전체 확대 기존
5 세션 묶음 (답 대기) 사용자 입력이나 승인을 대기 중인 세션, 주황색 강조 점(#e8590c) 제목 또는 상태 클릭 시 대기 중인 프롬프트/승인 입력창으로 화면 즉시 포커스 기존
6 세션 묶음 (끝남) 완료되거나 종료된 세션(TUI 세션 포함), 회색 점(#b8c4cf) 더블클릭 시 최종 산출물 및 완료 요약 로그 뷰어 표시 기존
7 메인 에이전트 카드 메인 에이전트명, 모델명, 누적 토큰 수, 현재 실행 중인 실시간 흐름 텍스트 한 줄 더블클릭 시 큰 카드(상세 콘솔/블록) 열기, 우클릭 시 메뉴(블록 추가/고정 등) 기존
8 서브에이전트 카드 & 연결선 메인 에이전트와 위계 연결선, 서브에이전트 모델명, 현재 수행 태스크, 경과 시간 더블클릭 시 서브에이전트 상세 카드 열기, 드래그 시 세션 내 카드 위치 조정 기존
9 잡 카드 실행 중인 백그라운드 프로세스(PID, 커맨드, 상태, 포트 번호 등) 더블클릭 시 프로세스 출력 스트림 로그 열기, 우클릭 시 잡 중단 메뉴 표시 기존
10 이 PC 카드 호스트 OS 정보(Win32 x64), 호스트 CPU/RAM 사용량, 디스크 여유 공간 더블클릭 시 상세 시스템 리소스 모니터 팝업 열기 기존
11 WSL·Docker 카드 WSL2 배포판 상태, 도커 실행 상태 및 활성 컨테이너 수, vCPU/메모리 점유율 더블클릭 시 WSL/컨테이너 리스트 및 상세 상태 팝업 열기 기존
12 미니맵 넓은 맵 캔버스 전체 조감도 및 현재 사용자의 화면 뷰포트 영역(주황 점선 박스) 미니맵 클릭 또는 드래그 시 해당 맵 위치로 즉시 팬(Pan) 이동 기존
