## OMP Live Map v8.2.1-preview.1

- 엔지니어링을 열면 **기초 생성** 화면에서 프로필, 하네스, 루프를 바로 만들 수 있습니다. 모델은 드롭다운으로 선택합니다.
- 프로젝트 없이 개인·팀 하네스와 루프를 만들고, 작업 프로젝트가 정해지면 Workflow에서 재사용할 수 있습니다.
- **기본 하네스·루프 만들기**로 설계, 리뷰, 개발 하네스와 테스트 루프를 한 번에 준비할 수 있습니다. 새 Workflow 템플릿에서 준비한 구성을 선택할 수 있습니다.

Windows x64 설치 파일과 SHA-256 체크섬을 제공합니다. 프리릴리스 설치 파일에는 코드 서명이 적용되지 않았습니다.
