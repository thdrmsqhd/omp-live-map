# 용어집

- **맵 세션**: 맵 서버가 띄운 상주 `omp --mode rpc-ui` 프로세스가 잡고 있는 세션. 맵에서 프롬프트 전송·취소·`ask` 응답을 한다.
- **TUI 세션**: omp TUI 프로세스가 잡고 있는 세션. 맵에서는 기록 tail로 보기만 하고 프롬프트를 보내지 못한다.
- **빈 세션**: 어떤 omp 프로세스도 잡고 있지 않은 세션. 프롬프트를 보내면 맵 세션이 된다.
- **세션 종료(stop)**: 맵 세션의 rpc 프로세스를 끝내 세션을 놓는 동작. 끝난 뒤에는 빈 세션이 되어 omp TUI로 이어 쓸 수 있다.
- **프로세스 정리**: 카드에서 띄운 백그라운드 잡과 cwd에 귀속된 프로세스를 끝내는 기존 동작(`POST /api/release`). omp 본체는 건드리지 않는다. 이전 메뉴 이름 "세션 프로세스 종료"를 이 이름으로 바꾼다.
- **중단됨**: 맵 서버가 내려가면서 턴 도중에 끊긴 맵 세션의 카드 상태. 사용자가 누르면 `omp --restore`로 이어 간다.
- **수동 전달**: 사용자가 누를 때 세션 A의 마지막 답변을 세션 B의 프롬프트로 넘기는 동작. 서버가 스스로 실행하지 않는다.
- **임시 표시**: rpc 이벤트로 그리는 진행 중인 글자·툴 호출. 기록 파일에 써지면 버리고 스냅샷으로 바꾼다.
- **카드**: 일하는 주체 하나. 메인 에이전트, 서브에이전트, 잡이 같은 틀(지금 하는 일이 실시간으로 흐르는 칸, 멈춤, 지시)을 쓴다.
- **실시간 흐름**: 카드의 주체가 지금 쓰는 글, 생각, 툴 호출과 인자, 결과, 잡 출력이 생기는 즉시 시간순으로 나오는 칸.
- **마이크로 관제**: 툴 호출 하나, 출력 한 줄 단위까지 보고 그 자리에서 멈추거나 지시하는 것.
- **모델 표시**: 카드에 붙는 모델 이름과 단가. 비싼 모델이 직접 일하는 카드를 눈에 띄게 한다.
